## Keeping a copy in this repository

A repository copy keeps the work available even if the Drive link changes. To add it:

1. Open the notebook in Colab.
2. Choose **File → Download → Download .ipynb**.
3. Save the file in this folder as `Hydroelectric_Power_Plant_Digital_Twin.ipynb`.

> Colab and the MATLAB/Simulink files model the same plant concept. Reference values (3 × 61.95 MW Francis units, 1 × 5.43 MW ecological unit, 191.28 MW total) and the modelling assumptions are the same across both workflows.

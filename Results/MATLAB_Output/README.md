# MATLAB Output

Figures exported from MATLAB after running `MATLAB/Plant_Model.m`. They show the model's own output for unit generation, sensitivity analyses, reservoir balance, 24-hour operation, generator, transformer, grid connection, protection scenarios and integrated operating cases.

The 37 PNG files in `Figures/` were renamed with a two-digit number and a descriptive English title. The number follows the order in which the figures were saved from MATLAB.

## Reproduce

Set MATLAB's *Current Folder* to the repository root and run `MATLAB/Export_Results.m`. It runs `Plant_Model.m` and writes automatically numbered exports (`MATLAB_Figure_XX.png`) and result tables to `Auto_Export/`. The curated, renamed figures above are kept separate from these automatic exports.

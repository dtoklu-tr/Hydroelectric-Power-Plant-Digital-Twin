# Project Structure Guide

- `MATLAB/`: calculation scripts and MATLAB usage notes.
- `Simulink/`: the Simulink block model and subsystem overview.
- `Reports/English/`: English reports in PDF and editable DOCX formats.
- `Reports/Turkish/`: Turkish reports in PDF and editable DOCX formats.
- `Results/Figures/`: presentation-ready PNG figures.
- `Results/Tables/`: CSV outputs for unit performance, sensitivities, operating schedules, reservoir balance, transformer currents, and integrated scenarios.
- `Results/generate_figures.py`: Python script that reproduces the companion charts from the stated project assumptions.
- `Colab/`: link and notes for the Google Colab notebook.
- `Assets/`: screenshots supplied with the Simulink model.
- `Documentation/`: methodology, assumptions, and repository guide.
